## Duplicate structure and inference limits

The clean set has 27,456 unique **unordered** exact raw sentence-pair hashes among 30,828 rows: 3,372 repeat rows, with 5,935 rows in 2,563 repeated unordered-pair groups. Only four repeated unordered-pair groups span more than one normalized page hash; the others repeat within a page. A read-only hash-only pass over raw `sent_a`/`sent_b` (no text displayed or exported) found 28,590 unique **ordered** pairs, 2,238 extra repeat rows, and 1,659 repeated ordered-pair groups. Their labels are internally consistent. There are 438 unordered-pair groups (953 rows) with both labels, but **every** such contrast is between reversed sentence orders: zero same-ordered-input groups have conflicting labels. These are label conflicts under an unordered representation. Reversal alone neither establishes a legitimate directional label difference nor proves annotation error; their cause has not been adjudicated. The unordered key is a conservative cross-split exclusion and dependence key for an ordered revision task; manuscript prose should distinguish it from identical ordered examples.

The primary estimand is row-weighted on a model-preselected Wikipedia release; repeated rows therefore affect the estimate. Page and exact-pair/revision connected-component bootstraps address observed dependence, but neither proves event independence, catches semantic near duplicates, or changes the release sampling mechanism. The sizable largest component and 29,879 rows in nontrivial components should be disclosed. The 220 excluded cross-split identities do not make the remaining test an independently sampled natural-news event test. The binary human-reviewed VitaminC label is not GMEE three-way relatedness, type/span, truth, provenance, or causal lineage gold. A manuscript should give the sparse comparator prominent treatment and avoid claiming isolated benefit from quantity, time, or provenance features; the 33-feature augmentation combines similarity, generic edit, and typed-change signals.

At this audit point, the original local lock intentionally has **no same-row ALBERT result**. A separately planned author-checkpoint analysis can be reported only with its own timestamp, code/data/checkpoint hashes, row alignment, and explicit post-primary status. Published author scores alone are not matched evidence. The broader GMEE natural-news paper still lacks two independent authenticated human reviews per pair and event-disjoint gold splits.
