# Public benchmark audit for the GMEE paper

Checked **19 October 2026** against dataset authors' papers and release pages. This is an access and label-semantics audit, not an experimental result. It does not change the status of GMEE's local labels: one authenticated human reviewer is not independent consensus gold.

## Label fit and access

## Paper decision without new reviewers

1. **Do not turn assistant labels into “human” votes.** An assistant can supply model-labeled development diagnostics, with model/version/prompt provenance, but it cannot create an independent second human or an adjudicated GMEE test set. Keep local one-reviewer pairs and historical machine votes exploratory. The [GMEE protocol](EVALUATION.md) already distinguishes these origins.
2. **Use only exact external targets.** An immediately accessible, defensible primary task is VitaminC binary factual-revision flagging from `vitaminc_flagging.zip`, provided the downloaded files and license are verified. Freeze hashes, preserve the authors' article-disjoint splits, and compare GMEE against matched text-diff, lexical, and model baselines. Treat numeric/date slices as secondary binary analyses, not numeric/temporal type accuracy.
3. **Pursue natural-news validation conditionally.** First locate or obtain the NewsEdits 2.0 human-gold annotation files and their rights. If available, evaluate factual versus style/narrative update detection on their exact labels, grouping all versions of an article and near-duplicate text. ClaimDiff can provide a separate cross-outlet comparison test only after specifying a genuine strengthen/weaken predictor; do not remap labels by name or tune on its test set.
4. **Narrow the manuscript to what these tests measure.** Public-benchmark results could support a component or transfer study. They cannot establish GMEE's proposed claim-evolution benchmark, exact typed-span accuracy, contextual correction handling, event generalization in the local news corpus, or publication acceptance. If those are central claims, the independent-human dependency remains open. Report the rights, missing gold, domain shift, and null results explicitly.

## Split and leakage checks before any run

- Record source version and hashes; deduplicate repeated/reversed claim pairs and cluster by article, revision chain, event/topic, and syndicated text as applicable. Do not derive labels from GMEE predictions or from similarity buckets.
- VitaminC: use `vitaminc_flagging.zip` for the binary factual-revision task; retain the article split and check exact input-pair overlap. `vitaminc_real` is the separate claim–evidence task, not the flagging data. Different revisions of the same article must not cross a new split.
- ClaimDiff: keep the released topic-disjoint train/test structure, verify topic and article identities in the files, and report `test-full` separately because its non-overlap sampling changes prevalence and label provenance.
- SemEval/MultiClaim: follow the official retrieval candidate pools and scorer; audit duplicate posts/fact checks and transitive links. Treat unobserved links as **unjudged**, not automatically negative.
- QuanTemp: audit claim/fact-check URL overlap and evidence publication time. Its fact-check verdicts are not passage-level stance labels for arbitrary retrieved snippets.

**Access unknowns:** NewsEdits 2.0 human-gold file location and exact redistribution terms; ClaimDiff and QuanTemp dataset-level licenses; whether institutional access to SemEval/MultiClaim is available. These must be resolved before planning experiments or public artifacts that depend on them.
