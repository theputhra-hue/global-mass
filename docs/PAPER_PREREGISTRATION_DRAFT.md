# GMEE preregistration — DRAFT, not locked

**Status (19 October 2026):** Design proposal for pilot review. This document is not a registered protocol, a frozen dataset, or evidence of a completed experiment. No primary outcome, sample size, threshold, or effect size is fixed yet. Record a dated, content-hashed locked revision **before** revealing final test labels or comparing test predictions. See [Research](RESEARCH.md) and the [paper readiness ledger](PAPER_READINESS_LEDGER.md).

## Candidate question and estimand

Can quantity-aware, source-anchored text comparison reduce unsupported numeric-change alarms on unseen news events while preserving detection of genuine numeric changes? This is a narrower, testable part of the broader quantity/context/provenance hypothesis. The intended unit is a natural claim pair; the uncertainty unit is its connected event group. A detected text change is not a falsehood, and an update is not evidence of copying.

**Candidate primary analysis for pilot validation:** On pairs independently judged to contain *equivalent quantities with no numeric drift*, compare the false-positive rate of `NUMERIC_DRIFT` for the full analyzer against the same analyzer with quantity equivalence normalization disabled. Report the paired difference (ablation minus full; positive favors the full analyzer) and its event-group interval. The current `claim-pairs-v2` rubric records change types, spans, and context but has no explicit quantity-equivalence field. The pilot must decide and validate an independent equivalence annotation and eligibility rule; otherwise this endpoint is ineligible. The ablation is planned, not implemented. Pilot results may justify a different **single** primary endpoint/contrast, recorded with a reason before locking and without looking at test outcomes.

## Sampling and independent reference labels

- Freeze an identified corpus snapshot of licensed, eligible article claims, with language, publication-date window, source policy, and extraction/model revision recorded. Define the candidate universe and retrieval settings before annotation: within-event candidates from a deterministic retrieval rule, plus probability-sampled low-similarity and cross-event controls. Record every stage's counts, exclusions, stratum sizes, and inclusion probabilities. Report performance for this sampled candidate task; estimate corpus-wide performance only if design weights and coverage support it.
- Curate event identity independently of the model's clusters. Group pairs sharing an event, claim, article, canonical/syndicated content, or identical normalized text into one component; manually audit near duplicates and event boundaries. Assign whole components to train/dev/test before fitting or selecting thresholds. Define any chronological/source stress sets separately.
- Pilot the versioned blinded rubric with at least two distinct authenticated human reviewers per pair. Annotate relatedness, mutation types, exact source spans, context, and the proposed quantity-equivalence target if retained. Keep revisions and dissent; establish adjudication, reviewer training, agreement reporting, and missing-versus-explicitly-empty rules. Machine, legacy, fixture, and single-reviewer labels cannot be test gold.

## Analysis plan to lock after pilot

- Implement the matched primary ablation with identical records, candidate universe, code revision, and inference budget. Fit any learned parameters on train; select policies on dev; evaluate test once. For the primary paired rate difference, resample connected event components with replacement and publish the interval, event count, eligible-pair count, and any undefined resamples. Decide the interval method and a smallest practically relevant effect using pilot event/type support, then freeze them.
- Secondary, explicitly non-primary analyses may include genuine `NUMERIC_DRIFT` recall, per-type/macro mutation F1, exact typed spans, contextual-relation errors, relatedness baselines, calibration, selective risk/coverage, equivalent-unit and correction error strata, source/temporal stress tests, and runtime. Name each baseline and ablation actually implemented. Predeclare any family of confirmatory secondary comparisons and its multiplicity rule; otherwise label these descriptive with intervals/support, not discoveries.
- Audit cross-split exact and near-duplicate content, canonical/syndication links, event identity, publication-time cutoff, annotator and model exposure to held-out material, and stored embedding provenance. Record residual unknown pretrained-data overlap. Use test labels only for the locked final analysis; a protocol change afterward requires a new version and disclosure.

## Lock and release gates still open

Before locking, decide: target population and candidate generator; equivalence rubric and eligible stratum; one primary endpoint/contrast and direction; minimum independent event and positive/negative/type support; precision or power rationale; smallest meaningful effect; recruitment/exclusion/stopping rules; grouped interval and undefined-metric handling; operating thresholds; secondary multiplicity policy; and who may access test labels. Stop collection by the predeclared rule, not when a result becomes favorable. Check source redistribution rights, annotator consent/privacy, and permitted release format before exporting text or votes. If independent gold or rights cannot be obtained, report that gate as unmet and do not present exploratory metrics as paper results.
